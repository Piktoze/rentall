# RentInOrbit V183 — brand and domain rebrand

Domain: https://rentinorbit.com

## Brand direction

- Core promise: **Anything. Anywhere. Rent it.**
- Main hero: **Rent what you need. Earn from what you own.**
- Positioning: one marketplace where individuals and businesses can both rent and rent out useful things, nearby or at a destination.
- Examples deliberately include occasion wear, chairs, tools and travel gear so the product is not perceived as travel-only or equipment-only.
- Orbit is used as a brand metaphor for keeping useful things in circulation, not as a literal space-rental theme.

## V183 changes

- Replaced the previous public branding with `RentInOrbit` across the website, help content, transactional copy, SEO-facing copy, PWA metadata and release documentation.
- Added canonical and Open Graph metadata for `https://rentinorbit.com/`.
- Updated PWA name/short name to RentInOrbit.
- Repositioned homepage copy from local-only rental to global two-sided rental marketplace.
- Added `Fashion & occasion wear` to primary customer/listing category selectors and highlighted fashion in quick discovery.
- Updated seller/rent-out messaging around earning from underused belongings.
- Updated onboarding and footer slogan.
- Updated visible brand references in supported LT/EN/ES/DE/RU translations.
- Bumped public asset cache version to V183 and shell cache to `rentinorbit-v183-shell`.
- Package identity moved to `rentinorbit-marketplace-mvp` RC48.
- Deployment examples point to `rentinorbit.com`.

## Compatibility note

V186 completed the technical naming migration. New runtime/configuration identifiers now use RentInOrbit naming, while a backward-compatible bridge reads existing pre-rebrand Railway variables and data locations during migration.
