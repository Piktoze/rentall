# RentInOrbit v191 — Similar alternatives

After a supplier declines or a request is auto-declined for no response, the renter sees up to six alternatives checked for the same dates and quantity. Alternatives prioritize same category/location, similar daily price and shorter configured response windows. Recovery suggestions exclude Instant Book listings so every replacement request still requires supplier confirmation.

The primary action carries the original dates and quantity into the new listing flow. The renter reviews the new request before it is sent.
